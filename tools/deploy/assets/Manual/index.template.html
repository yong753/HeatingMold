1. 시작하기 전에

이 배포본은 설치 과정이 없습니다. 압축을 풀고 시작 파일을 실행하면 바로 동작합니다.

운영체제Windows 10 64비트 또는 Windows 11 (64비트). 32비트 Windows 에서는 실행되지 않습니다.
설치 필요 항목없습니다. .NET 데스크톱 런타임과 Visual C++ 재배포 DLL 이 패키지 안에 함께 들어 있습니다.
관리자 권한필요 없습니다. 시스템 폴더나 레지스트리를 변경하지 않습니다.
인터넷필요 없습니다. 완전 오프라인으로 동작합니다.
그래픽3D 뷰포트는 OpenGL 을 사용합니다. 원격 데스크톱이나 일부 가상 환경에서는 3D 표시가 실패할 수 있습니다.
권장 화면1920×1080 이상. 배율 100~150% 에서 사용하도록 확인했습니다.
압축을 먼저 푸세요 ZIP 파일 안에서 바로 실행하면 일부 파일을 읽지 못해 시작에 실패할 수 있습니다. 반드시 폴더에 압축을 푼 뒤 실행하십시오.

2. 압축 풀기와 실행

  1. 받은 ZIP 파일을 원하는 폴더에 압축 해제합니다.
  2. 압축을 푼 폴더에서 HeatingMold.Start.exe 를 실행합니다. 이것이 유일한 실행 파일입니다.
  3. 시작 도구가 패키지 파일을 점검하고 앱을 실행합니다. 점검에 실패하면 이유를 알려 주는 창이 뜹니다.
  4. 앱 창이 열리면 상단의 예제 열기 로 기본 예제 모델을 불러옵니다.
시작 도구가 하는 일 실행 위치와 Windows 버전, 패키지 파일의 무결성(체크섬)을 확인한 뒤 앱을 실행합니다. 앱을 실행한 뒤 시작 도구는 스스로 종료되며, 앱은 계속 열려 있습니다.
진단 옵션 HeatingMold.Start.exe --check-only 는 앱을 실행하지 않고 점검 결과만 보여 줍니다. --diagnostics 는 로그 폴더를 엽니다. 문의할 때 이 폴더의 파일을 함께 보내 주십시오.

3. 화면 구성

  • 상단 오른쪽: 시각 테스트…, 프로젝트 열기…, 다른 이름으로 저장…, 예제 열기.
  • 뷰포트 위쪽 두 줄은 발열경로 편집과 영역 제외의 도움말입니다.
  • 오른쪽 탭: 영역·경로·검토·내보내기.
  • 맨 아래 상태 줄에 마지막 동작의 결과가 표시됩니다. 작업 후에는 이 줄을 먼저 확인하십시오.

각 탭의 주요 입력은 다음과 같습니다.

  • 영역: 선택한 면 목록, 영역 추가·삭제.
  • 경로: 배치 방향, 시작·종료 인출점, 발열사 케이스, 발열사 외곽 간격, 삽입 깊이, 패턴 생성.
  • 검토: 발열 전력(전체 합계 한도), 허용 전압·전류, 회로별 전기 사양표, 자동 분할.
  • 내보내기: 내보낼 검토 범위와 DXF·STEP 내보내기.

4. 모델 열기

  1. 예제 열기: 기본 예제 모델(Mold_Cover_Trim.step)을 엽니다. 동작 확인용입니다.
  2. 프로젝트 열기…: 저장된 JSON 프로젝트를 열고 원본 STEP을 함께 불러옵니다. 원본 STEP을 찾지 못하면 다시 선택하며, 저장 당시와 체크섬이 같아야 합니다.
  3. 파일을 열면 작업 방향(작업 법선)이 자동으로 결정되고 화면이 그 방향의 정면으로 정렬됩니다.
작업 방향을 먼저 확인하세요 오른쪽 작업 방향 상자에 법선 벡터가 표시됩니다. 3D 뷰포트에서 작업 정면으로 돌아가기 를 누르면 언제든 그 방향의 정면으로 돌아옵니다.

5. 발열면 선택과 영역 확정

  1. 뷰포트에서 면을 클릭합니다. Ctrl+클릭으로 추가·제외, Shift+드래그로 사각형 안의 면을 한 번에 선택합니다(기존 선택은 교체됩니다).
  2. 선택한 면이 목록에 표시되고 개수가 함께 나옵니다.
  3. Enter 또는 영역 추가 를 눌러 작업 영역으로 확정합니다.
영역은 독립적으로 동작합니다 확정한 영역은 각각 독립된 발열영역입니다. 한 영역을 수정해도 다른 영역의 확정 경로는 바뀌지 않습니다. 서로 다른 영역의 발열영역이 겹치지 않도록 선택하십시오.

6. 시작·종료 인출점 선택

  • 인출점은 반드시 영역 경계 위에서 선택해야 합니다. 경계 밖을 클릭하면 선택되지 않습니다.
  • 선택한 점은 이후 저장·복원에서도 같은 경계(원본 CAD 모서리 또는 제외·절단 경계)에 그대로 묶입니다.
  • 인출점을 바꾸면 경로를 다시 생성해야 합니다.

7. 마진·간격·방향과 경로 생성

배치 방향가로(Frame X) 또는 세로(Frame Y). 사행의 진행 방향을 정합니다.
마진 (mm)영역 외곽과 제외영역에서 발열사를 띄우는 거리입니다.
발열사 케이스Case 1: SUS 316L Ø0.30 mm / 4 Ω/m · Case 2: Ø0.15 mm / 8 Ω/m. 경로를 만들 때 적용되는 규격이며 모든 영역에 공통입니다.
발열사 외곽 간격 (mm)이웃한 발열사 바깥 면 사이의 거리입니다. 기본 5 mm.
경로 중심 간격외곽 간격에 선택한 케이스의 직경을 더해 자동으로 정해집니다. 예를 들어 외곽 5 mm 는 Case 1 에서 중심 5.3 mm, Case 2 에서 중심 5.15 mm 입니다. 별도로 입력하지 않습니다.
삽입 깊이현재 버전은 0 mm 만 지원합니다.
발열사 케이스는 경로 생성 입력입니다 케이스를 바꿔도 이미 확정된 경로·길이·인출점을 지우거나 자동으로 다시 만들지 않습니다. 대신 해당 영역을 재생성 필요 로 표시합니다. 생성 당시 적용한 직경은 그대로 보존되며, 새 케이스를 적용하려면 경로를 다시 생성해야 합니다.
  1. 값을 입력하고 패턴 생성 을 누릅니다.
  2. 상태 줄에서 조각 수와 총 길이를 확인합니다.
  3. 결과가 마음에 들지 않으면 값을 바꿔 다시 생성합니다. 이전 경로는 새 결과로 교체됩니다.
경로 길이 표시 각 레인과 회전 구간 위에 실제 3D 길이가 표시됩니다. 값이 많아 복잡할 때는 확대해서 확인하십시오.
발열사 간격 표시 경로를 확정하거나 프로젝트를 열면 인접한 두 레인마다 가장 좁은 지점 한 곳에 실제 외곽 간격이 표시됩니다. 영역 색의 눈금선·치수선과 숫자로 나타나며, 표시는 확인용일 뿐 경로·길이·전기 판정을 바꾸지 않습니다. 1 mm 간격으로 표본을 확인하므로 그보다 좁은 구간의 이상을 모두 검출한다고 보장하지는 않습니다. 방향이 다른 레인 묶음은 서로 비교하지 않습니다.

8. 제외영역

  1. 영역 제외 를 체크합니다.
  2. 뷰포트에서 사각형을 드래그합니다. Esc 로 진행 중인 드래그를 취소합니다.
  3. 제외영역을 반영하려면 경로를 다시 생성합니다.
허용되지 않는 제외영역 작업영역 안에 구멍을 만들거나 영역을 둘 이상으로 분리하는 제외영역은 허용되지 않습니다. 외곽을 깎는 형태만 사용할 수 있으며, 조건을 어기면 기존 제외영역과 경로가 그대로 유지된 채 거부됩니다.

9. 꼭지점 편집

  • 꼭지점은 발열 진행 방향으로만 움직입니다. 가로 생성이면 좌우, 세로 생성이면 상하입니다.
  • 진행 방향과 수직인 이동은 적용되지 않으므로 발열사 간격이 유지됩니다.
  • 드래그 중에는 표시용 미리보기만 보이고, 마우스를 놓을 때 검증 후 확정됩니다.
  • 시작·종료 인출점은 꼭지점 편집 대상이 아닙니다. 인출점은 6장의 방법으로 바꿉니다.

10. 전기 검토와 판정

발열 전력 (kW)프로젝트 전체가 함께 사용하는 총 한도입니다. 영역별로 따로 주어지는 값이 아닙니다.
허용 전압 (V)회로 하나에 허용되는 최대 전압입니다. 기본 220 V.
허용 전류 (A)회로 하나에 허용되는 최대 전류입니다. 기본 16 A.
  • 총 발열 전력은 확정된 모든 영역의 회로에 실제 3D 길이 비율로 배분됩니다.
  • 각 회로의 필요 전압과 전류는 그 배분값으로 계산합니다.
  • 어느 한 회로라도 허용 전압이나 허용 전류를 넘으면 그 회로는 NG 입니다.
  • 배분된 전력의 합계가 입력한 총 한도를 넘으면 전체가 NG 입니다.
  • 판정이 OK 인 회로의 행은 초록색, NG 인 회로의 행은 빨간색으로 표시됩니다.
  • 발열사 케이스와 외곽 간격은 경로 탭에서 정합니다. 검토 탭에서는 케이스를 바꾸지 않습니다.
  • 생성 후 케이스를 바꾸면 확정 경로·길이·인출점은 그대로 유지됩니다. 표에는 회로 ID 와 확정 실측 길이가 남고, 전력·저항·전압·전류는 공란, 판정은 —, 비고는 케이스 변경 — 재생성 필요 · 이전 확정 길이 로 표시됩니다. 원래 케이스로 되돌리면 경로를 다시 만들지 않아도 계산 표시가 복원됩니다.
영역을 나눠도 총 전력은 늘지 않습니다 한 영역을 둘로 나누면 두 영역이 총 한도를 나눠 씁니다. 나눈 뒤에도 초과한다면 발열사 사양이나 조건을 바꿔야 합니다.

11. 자동 분할

  1. 검토 탭에서 조건을 확인하고 자동 분할 을 실행합니다.
  2. 확인 창에서 승인하면 분할이 진행됩니다.
  3. 분할 뒤 각 영역은 독립 영역이 되어 따로 선택·수정할 수 있습니다.
  • 한 번의 자동 분할로 만들 수 있는 영역은 최대 4개 입니다. 그보다 많이 필요하면 분할하지 않고 오류를 알립니다.
  • 시작·종료 인출점은 분할 전과 같은 쪽(측면)을 유지합니다. 길이를 맞추기 위해 인출점을 임의로 바꾸지 않습니다.
  • 분할 결과의 2D 경로 길이 편차가 상태 줄에 표시됩니다. 편차가 남아도 분할은 확정됩니다.
  • 분할에 실패하거나 취소하면 원래 영역과 경로가 그대로 유지됩니다.
  • 자동 분할은 이미 확정된 발열 레인을 연속된 묶음으로 나누는 방식입니다. 레인을 새로 만들지 않고, 묶음 경계의 연결만 새 인출점에 맞춥니다.
  • 따라서 경로를 먼저 생성해야 하며, 확정된 경로가 없으면 분할하지 않고 먼저 생성을 안내합니다.
  • 길이 편차는 확정된 조각 길이의 합(레인·턴·연결 포함)을 기준으로 계산합니다.

12. 프로젝트 저장과 복원

  • 프로젝트 파일은 JSON 한 개이며, 원본 STEP 을 내장하지 않습니다. STEP 파일의 경로와 체크섬만 기록합니다.
  • 따라서 프로젝트와 원본 STEP 을 같은 상대 위치로 함께 보관해야 합니다.
  • 원본 STEP 이 없거나 내용이 바뀌면 복원이 거부됩니다.
  • 현재 버전에서 저장한 프로젝트만 열 수 있습니다. 이전 버전 형식은 열리지 않고 안내가 표시됩니다.

13. DXF·STEP 내보내기

  • DXF 좌표는 확정 작업평면의 원점과 축을 그대로 사용합니다. 최소 모서리로 재정렬하지 않습니다.
  • 발열경로는 영역 색으로 그려지고, 각 레인·회전 구간의 실제 길이가 함께 표시됩니다.
  • 전기 사양표의 행은 내보낸 회로와 1:1로 대응합니다.
  • STEP 에는 모델 원본, 영역별 발열사(실제 직경의 솔리드), 영역별 발열경로(중심선)가 함께 들어갑니다.
  • 발열면은 영역 색으로 칠해집니다.
  • 길이 치수와 전기 사양표는 DXF 에만 들어가고 STEP 에는 들어가지 않습니다.
  • 내보내기는 현재 검토 범위를 따릅니다. 전체 또는 현재 영역만 내보낼 수 있습니다.
