HeatingMold 테스트 배포본 — 처음 읽어주세요
=================================================

이 폴더는 HeatingMold 테스트 프로그램의 오프라인 배포본입니다.
설치 과정이 없으며, 압축을 푼 뒤 HeatingMold.Start.exe 를 실행하면 됩니다.


1. 실행 방법
-------------------------------------------------
  1) ZIP 파일을 PC의 원하는 폴더에 압축 해제합니다.
     - ZIP 파일 안에서 직접 실행하지 마세요. 반드시 먼저 압축을 풀어야 합니다.
     - 폴더 이름과 경로에 한글이 있어도 동작합니다.
  2) HeatingMold.Start.exe 를 더블클릭합니다.
  3) 시작 도구가 패키지 무결성을 확인한 뒤 자동으로 응용 프로그램을 실행합니다.

  시작 도구는 Windows 10 64비트 이상에서 동작하며, 관리자 권한을 요청하지 않습니다.


2. 준비물
-------------------------------------------------
  - Windows 10 64비트 또는 Windows 11 64비트
  - 64비트 CPU, 4 GB 이상 메모리, OpenGL 을 지원하는 그래픽 드라이버
  - .NET 런타임 설치 불필요 (패키지에 포함)
  - Visual C++ 재배포 설치 불필요 (패키지에 포함)
  - 인터넷 연결 불필요


3. 예제 모델 열기
-------------------------------------------------
  앱 실행 후 "예제 열기" 를 누르면 패키지에 포함된 예제 모델이 열립니다.
  예제 파일 위치: App\resource\Mold_Cover_Trim.step
  이 파일의 이름이나 위치를 바꾸면 예제 열기가 동작하지 않습니다.


4. 파일 구성
-------------------------------------------------
  HeatingMold.Start.exe      시작/점검 도구 (이 파일을 실행하세요)
  App\                       응용 프로그램과 런타임 파일
  App\deployment.json        배포 구성 정보 (수정하지 마세요)
  App\occt-resources\        CAD 커널 런타임 리소스
  Manual\                    사용 설명서 (스크린샷 포함)
  Licenses\                  제3자 라이선스 원문
  manifest.sha256            패키지 무결성 목록 (수정하지 마세요)
  build-info.json            빌드 정보


5. 문제가 있을 때
-------------------------------------------------
  시작 도구가 실행되지 않거나 앱이 바로 종료되면 다음 순서로 확인하세요.

  1) 명령 프롬프트에서 이 폴더로 이동한 뒤 진단 모드를 실행합니다.
         HeatingMold.Start.exe --check-only
     - 패키지 무결성, Windows 버전, 64비트 여부를 검사하고 결과를 보여줍니다.
         HeatingMold.Start.exe --diagnostics
     - 로그 폴더를 엽니다.

  2) 로그 위치
         %LOCALAPPDATA%\HeatingMold\Logs\
     - launcher.log   : 시작 도구 기록
     - <세션폴더>\app.log, environment.json, occ_viewer_log.txt : 앱 기록

  3) 문의할 때는 위 로그 폴더를 통째로 압축해 함께 보내주세요.
     모델 파일은 자동으로 첨부되지 않습니다. 필요한 경우에만 직접 첨부하세요.

  "무결성 검사 실패" 가 나오면 압축 해제가 중간에 끊겼거나 파일이 변조된 것입니다.
  ZIP 파일을 다시 받아 새 폴더에 압축을 푸세요.


6. 알려진 제한 (테스트 배포본)
-------------------------------------------------
  - 자동 분할은 한 번에 최대 4개 영역까지 지원합니다.
  - 경로 표면 검증은 1 mm 간격 표본으로 확인합니다. 표본 사이의 더 좁은 결함은
    검출되지 않을 수 있습니다.
  - DXF 는 확정 작업면의 평면도만 출력합니다. 3D 형상은 STEP 으로 출력합니다.
  - STEP 의 발열경로 중심선(edge) 파트는 일부 CAD(예: FreeCAD)에서 표시되지 않습니다.
    이는 파일 구조 문제가 아니라 해당 CAD 의 가져오기 제한입니다.
  - 프로젝트 파일(.json)은 원본 STEP 을 내장하지 않습니다. 프로젝트를 옮길 때는
    같은 위치에 원본 STEP 도 함께 있어야 합니다.

  이 배포본은 평가/테스트 목적입니다. 실제 생산 적용 전에 대상 PC 에서
  모델 열기 → 영역/인출점 → 생성 → 전기검토 → 저장/복원 → DXF/STEP 출력까지
  직접 확인하시기 바랍니다.
