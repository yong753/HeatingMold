HeatingMold 릴리스 노트
=================================================

정확한 빌드 정보(버전, Git 커밋, 빌드 시각, 포함된 네이티브 DLL 수, VC 재배포 버전)는
패키지 루트의 build-info.json 을 확인하세요.

이 파일은 Build-Package.ps1 -ReleaseNotesPath <파일> 로 교체할 수 있습니다.


배포 형태
-------------------------------------------------
  - 오프라인 ZIP 배포본 (self-contained, 다중 파일)
  - .NET 8 데스크톱 런타임 포함
  - Visual C++ 재배포 런타임 app-local 포함 (관리자 권한 불필요)
  - Open CASCADE Technology 7.9.3 런타임 및 리소스 포함


지원 환경
-------------------------------------------------
  - Windows 10 64비트, Windows 11 64비트
  - OpenGL 2.1 이상을 제공하는 그래픽 드라이버
  - 64비트 전용 (32비트 미지원)


변경 사항
-------------------------------------------------
  - 발열사 케이스를 경로 탭의 생성 입력으로 옮겼습니다. 생성 후 케이스를 바꿔도
    확정 경로·길이·인출점은 유지되고, 검토 표는 회로 ID 와 확정 실측 길이를 남긴 채
    재생성 필요를 표시합니다.
  - '발열사 외곽 간격'을 입력하면 선택한 케이스 직경으로 레인 중심 간격을 자동 계산합니다.
  - 경로 확정 또는 프로젝트 복원 시 인접 레인의 가장 좁은 지점에 실제 발열사 간격을
    뷰포트에 표시합니다.
  - 자동 분할이 이미 확정된 발열 레인을 연속 묶음으로 나누는 방식으로 바뀌었습니다.
    경로를 먼저 생성해야 하며, 분할 후에도 시작·종료 인출점은 같은 측면을 유지합니다.
    한 번에 최대 4개 영역까지 나눌 수 있습니다.
  - 전기 검토 표에서 판정 OK 행은 초록색, NG 행은 빨간색으로 표시됩니다.
  - 상단에서 STEP 열기·저장 버튼을 제거하고 '다른 이름으로 저장'만 남겼습니다.


알려진 제한
-------------------------------------------------
  - 자동 분할 최대 4개 영역
  - 경로 표면 검증 표본 간격 1 mm
  - DXF: 확정 작업면 평면도 + 발열경로 + 전기 사양표
  - STEP: 모델 + 발열영역 면 색상 + 발열사 솔리드 + 발열경로 중심선
  - 일부 CAD 는 STEP 의 edge-only 파트(발열경로 중심선)를 가져오지 않습니다.
  - 프로젝트 json 은 원본 STEP 을 내장하지 않습니다.


배포 담당자 확인 사항
-------------------------------------------------
  - .NET 8 은 2026-11-10 에 Microsoft 지원이 종료되었습니다. 외부에 장기 배포하려면
    지원 중인 .NET 버전으로 전환하고 동일한 검증을 다시 수행할 것을 권장합니다.
  - 제3자 라이선스 재배포 조건은 THIRD-PARTY-NOTICES.txt 와 Licenses 폴더를 확인하세요.
  - 배포 대상 CAD 모델의 외부 전달 권한을 확인하세요.
