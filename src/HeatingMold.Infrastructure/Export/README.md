# Infrastructure.Export

Export writers consume an immutable `ExportSnapshot`, so they do not reread mutable session state or recompute design and electrical values.

`DxfProjectionBuilder` projects effective region boundaries and measured 3D heating/connection curves into the snapshot's working plane. It also draws a cross at each external connection point and labels it with the circuit sequence and start/end role on `HEAT_CONNECTION_POINT`. `DxfLayerCatalog` keeps layer names in one place, and `SpecificationDataBuilder` builds circuit rows from the same revision's 3D length ledger, area allocation, and electrical results. The writer stores labels and table cells as editable `TEXT` and grid edges as `LINE`, marks drawing insertion units as millimeters, and writes through a temporary file before replacing the destination. Cancellation or a write failure after serialization removes the temporary file and preserves an existing destination. Missing inputs remain visible as `Unavailable` or `Not calculated` instead of becoming zero or a passing result.

The DXF contains measured design geometry; its notes distinguish 3D specification lengths from 2D projected lengths and explain that separate connection wire is excluded from resistance length.

`StepDesignPayloadBuilder` maps final curve snapshots into circuit heating wires and connection-point wires while retaining circuit traversal direction. Curves without a circuit remain in a named unassigned group. `StepDesignWriter` asks the OCCT bridge to write a sibling temporary STEP file, checks that it is nonempty, and replaces the destination only after success. Cancellation during the bridge call discards the temporary output and preserves the previous destination. The native writer transfers each group as a compound and can include the captured source STEP shape. The Native writer now rereads the written file and compares edge count, unordered endpoints, and measured edge lengths against the pre-write source plus design geometry. `WorkingSide.Regression` covers exports with and without the source model. This Native implementation is not compiled in the current environment. STEP root names and third-party CAD validation remain pending.
