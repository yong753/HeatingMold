## 3. 곡면 관찰 (E5)

- 평면 #626: UV↔3D 길이 비율 1.0000 — UV 공간 등방, 사행 성립
- 원통면 #4: UV u=0.058rad(각도 단위) · v=127.7mm — **비등방으로 UV 기반 사행 불가** (NO SEGMENTS)
- 결론: 곡면 패턴화는 UV 스케일 보정·전개 후 본 개발 과제
