# 발열몰드 현재 상태 (단일 현황)

- 최종 갱신: **2026-11-15**
- 이 문서의 목적: 구현·사용자 정책·확인된 검증·실 검증 대기·남은 순서를 한 곳에 유지한다.
  세부 이력은 `AGENTS.md`에 남아 있고, 이 문서는 그중 **현재 유효한 것만** 요약한다.

## 1. 결론

- 표면 미검출 짧은 구간의 **10 mm 제한 근사 연결**은 구현되었고, 독립 리뷰 **6건** 보완과
  자동 검증(Core·App·WorkingSide·가드)까지 끝났다.
- **사용자 실 CAD의 A 영역 0.2 mm 전체 생성 결과는 아직 받지 못했다. 해결이 확정된 것이 아니다.**
  통과한 자동 suite를 실 CAD 해결로 치환하지 않는다.
- 진행 중인 실행을 새로 시작하거나 중복 실행하지 않고 **결과를 기다린다**.
  진행 상황을 확인하려고 중간 산출물을 읽거나 프로세스를 조회하지 않는다.

## 2. 사용자 최신 정책 (표면 미검출 근사)

- 목표는 정밀 표면 일치가 아니라 **대략적으로 보이는 경로**다.
- **순수 표면 Miss**만 근사 대상이다. 허용 조건은 앞뒤 실제 정상점 사이
  **원래 2D 경로 진행 길이 ≤ 10.0 mm** **그리고** **3D 직선거리 ≤ 10.0 mm**(둘 다).
- **누락 개수 고정 상한 없음**(기존 자원 예산은 별도로 그대로 적용). 서로 떨어진 누락 구간은
  **각각 독립 판정**한다.
- **인출점·원본 조각 끝점·원래 꺾임점은 절대 생략하지 않는다.**
- 판정 순서: **strict → 원래 성립하는 평면 턴 외곽 예외(5 mm) → 제한 근사**. 기존에 성립하던
  2점 턴 결과가 근사 때문에 바뀌지 않도록 근사를 턴 예외 뒤에 둔다.
- 정상 Hit는 좌표 **±0 비트까지 그대로** 반환하고, 일반 성공 구간 chord 0.05 mm 검사와
  strict의 **1 mm 보강 조회**는 유지한다.
- typed **Hard**(커널 오류, 오래된 컨텍스트, malformed Hit, 모호/겹침 경계, 자원·깊이 한도)는
  근사하지 않는다. 후보는 `선택 면 → 전역 표면 → 정확 경계` 순서로 **유효 Hit가 먼저 이기고**,
  한 번 관측한 hard를 재조회로 지우지 않는다(strict 시도 중 관측값을 값으로 기록).
- 실패 시 **부분 결과 없음**, 기존 영역·경로·선택점 보존, **단일 원자적 커밋**.
- 근사 연결 내부에 가짜 3D 점이나 가짜 supportFace를 만들지 않으며, 점별 support의 네이티브
  검증은 그대로 통과해야 한다.

## 3. 캐시·통계·저장·출력 원천

- 근사·턴 예외 표본은 **strict 표본 캐시에 넣지 않는다**. 검증 키는 `strict-v4` + 근사 정책 값
  (버전/10 mm/조회 간격)을 포함하고, retain 키도 같은 접두부를 써서 함께 분리된다.
- 완료 통계는 **이번 준비에서 실행한 근사만** 센다. retain·캐시 적중 조각은 포함되지 않으며,
  schema 7에는 근사 메타데이터가 없으므로 **로드 직후의 0을 "전체 근사 없음"으로 해석하지 않는다.**
- schema 7은 **실제 확정 xyz + 점별 supportFace + 실측 길이**를 저장하고, 복원은 **재투영 없이**
  그 값을 그대로 스테이징한다.
- 전기 계산·길이 라벨·DXF·STEP은 모두 **그 확정 native chain 하나**를 원천으로 쓴다(코드상 공통
  원천). 다만 **이번 5,000조각 전체의 실제 DXF/STEP 산출물 성공은 아직 확인하지 않았다.**

## 4. 검증 실행 가드 (완료)

- 가드 자체 회귀 **112 PASS / 0 FAIL**, 실제 App 7단계 스모크 **7/7 Completed**, 성공 후 앱 창 유지.
- root를 private job으로 소유하고, 예상치 못한 모달을 만나면 **기록 후 그 검증 tree만** 실패 정리한다.
  정상 제품 대화상자 동작은 바꾸지 않는다.
- 사용법: `docs/ValidationGuard.md`, `tools/validation/README.md`.

## 5. 원본 / 계산용 sewn 사본 분리 (완료)

- 제품 기본 표면 조회는 **원본 `g_shape`/`g_faces`**다. 계산용 1 mm 재봉 사본은 **시험 전용
  opt-in**이며, 환경변수 `HEATINGMOLD_USE_CALC_SEWN_COPY` 값이 **정확히 ASCII `1` 한 글자**일 때만
  켜진다. 이 값은 **모델을 (재)로드할 때만** 읽으므로 로드 시점 snapshot으로 동작한다.
- 원래 0.2 mm 재현에서 실패한 표본(5,000조각 중 lane 268, HeatingRun 537번째)의 작업평면
  `(-489.81391714892175, -32.960668248954725)`은 **strict 기준**으로 선택 면·전역 표면 Miss +
  경계 `NoIntersection`이었다. 재봉 사본에서 추가로 보이던 6개 `GeometryFailure`는 **원본에서는
  Hit**다.
- 실패 광선은 위상적으로 같은 edge를 공유하는 두 BSpline patch(face 57/58) 사이를 지난다. 그
  표현 차이는 CAD 기록 tolerance 범위 안이지만, 이것만으로 **실제 physical hole / 모델 전체
  invalid / solver 무결함을 단정하지 않는다.**
- 이 계획의 2단계는 **실패 조각의 국소 연속 방향 투영 시제품**(원본 곡선의 전면 교체가 아니다)이며
  **미구현**이다. 0~1단계 진단은 완료되었고, 그 gate는 **최신 근사 승인의 선행 조건이 아니다**.

## 7. 실 CAD 남은 확인 (A 영역 0.2 mm) — 아직 미확인

- 대상: 저장된 `261116_Test2.json` **사본**과 그 저장 exit를 그대로 사용한다.
  A = 59면, FrameY, 외곽 간격 0.2, Case1(Ø0.30/4 Ω/m), 중심 피치 0.5
  → 목표 **2,500 레인 / 5,000 조각 / 1 회로**.
- B = 29면, 기존 확정 472조각 `80189.26162223217 mm`는 **깊은 복사 스냅샷으로 실행 전후를 엄격
  비교**해 확정 경로·길이·표본·binding 등이 변하지 않았음을 확인해야 한다(수용 기준).
- A는 저장된 시작/종료 인출점의 **원본 CAD edge/parameter/binding을 그대로 유지**해야 한다.
- 두 경우 모두 실패하면 **부분 결과가 없어야** 한다.
- 남은 검증은 **서로 다른 두 실행**이며, 지금 새로 시작하라는 뜻이 아니라 진행 중 결과를 받은 뒤의
  계획이다. ① 현재 진행 중인 **구판 App `3916E531…`** 실행의 A 0.2 mm 결과 수신,
  ② **최종 `iso6`(`427E502D…`)에서 같은 입력으로 A 0.2 mm를 fresh 확인**(①과 별개 검증).
- 각 실행은 **처음부터 실제 loaded DLL을 확인하는 것을 전제**로 한다(마지막에 최초 확인하는 단계가 아니다).
- ②에서 빠뜨리면 안 되는 항목:
  1. 저장 → **같은 프로세스 재로드**로 xyz/support/length/points 일치.
  2. 전기·DXF 값 일치.
  3. **2 mm 대조로 old strict와 bits 비교**.
  4. 그 뒤에 최종 **shared bin 배치**.
- 현재 진행 중인 단계가 **구판 `3916E531…`** 기준이라는 점을 최종 `427E502D…` 확인과 혼동하지 않는다.
- **5,000조각 전체 STEP 자동 실행은 금지**한다. 부분 payload는 전체 완료가 아니다.
- 여전히 미검증: 실제 마우스 조작, 화면 육안 판정, DPI 변경, 새 프로세스에서의 프로젝트 복원,
  외부 CAD에서 DXF/STEP 열기.

## 8. 성능 해석 주의

- 10 mm 근사는 **실패 허용 정책**이며 성능 최적화가 아니다. 1 mm 보강 조회와 점별 native 지지면
  검증은 근사 후에도 그대로다. `Generate_Click` 시간에는 커밋 후 길이 라벨 재배치와 간격 표시가
  포함된다.
- 길이 라벨 엔진은 라벨마다 **자기 조각을 제외한 전체 route 구간 목록**을 새로 만들고 배치된
  라벨·전체 선분과의 겹침을 검색한다(정적 관측). **어느 단계가 병목인지, 개선 배율은 미계측**이다.
- A(5,000 신규 생성)와 B(472 복원/보존)는 **서로 다른 작업**이므로 생성 속도 비교가 아니다.
- 완료된 **old strict 2 mm 기준선** `control2mm-20261115-022009`: `load.result.seconds` 21.961,
  `generation.seconds` 223.871, 보고된 total 247.514. 1,088조각 / 544레인 / 543턴 / 1회로 /
  `227149.59715059225 mm` / 평면 턴 예외 1건. **B만의 시간이 아니고, 새 `iso6`나 현재 0.2 mm
  실행 시간도 아니다.**
- old 2 mm 기준선은 3회 실행되었고 그중 2회가 독립 bits 0 diff였다. 세부 run별 수치를 서로
  재혼합하지 않는다.
