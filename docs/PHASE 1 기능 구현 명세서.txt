발열몰드 자동설계 프로그램
PHASE 1 구현 범위 안내
================================================================

1. 프로그램 개요
----------------------------------------------------------------
발열몰드의 3D 모델(STEP/STP)을 불러오면, 입력한 전기·발열 조건에 맞춰
발열사 경로를 3D 모델 위에 자동으로 생성하고, 2D 도면과 전기 사양표를
출력하는 Windows용 데스크탑 프로그램입니다.

- 별도 실행 프로그램입니다. 특정 CAD의 플러그인이 아니므로 사용하는
  CAD 프로그램과 관계없이 사용할 수 있습니다.
- 입력 : STEP/STP 모델
- 출력 : 3D 발열사 경로(STEP/STP), 2D 도면(DXF), 전기 사양표
- 화면은 기본 형태로 제공합니다.


2. 기능 명세
----------------------------------------------------------------
각 기능은 "기능 번호 / 설명 / 입력 / 출력 / 비고"로 정의합니다.

기능 요약
   ① 형상 및 설계 조건 입력 : FR-1.1 ~ FR-1.5
   ② 발열사 경로 자동 생성 : FR-2.1 ~ FR-2.6
   ③ 전기적 조건 검토 및 회로 구성 : FR-3.1 ~ FR-3.4
   ④ 결과 확인 및 저장 : FR-4.1 ~ FR-4.3

작업 순서
   모델 불러오기 -> 적용면 선택 -> 조건 입력 -> 경로 생성
   -> 전기 검토·회로 구성 -> 결과 확인 -> 저장


■ ① 형상 및 설계 조건 입력

FR-1.1  STEP/STP 모델 불러오기
   설명 : STEP/STP 형식의 3D 모델을 불러와 화면에 표시한다.
   입력 : STEP/STP 파일
   출력 : 화면의 3D 모델 (회전·확대·축소 가능)
   비고 : -

FR-1.2  적용면 선택
   설명 : 발열사를 배치할 면(적용면)을 선택한다. 하나의 발열면이 여러
          면으로 나뉘어 있는 경우 여러 면을 함께 선택할 수 있다.
   입력 : 화면에서 클릭, 또는 면 목록에서 선택
   출력 : 선택된 적용면
   비고 : 선택 방식은 협의 (1)

FR-1.3  전기 조건 입력
   설명 : 발열사 직경, 단위 길이당 저항, 사용 전압(또는 최대 허용
          전압), 허용 전류·전력, 기준 발열량을 입력한다.
   입력 : 숫자 입력
   출력 : 전기 계산에 사용할 값
   비고 : 값과 계산식은 발주처 제공 자료 기준

FR-1.4  발열사 간격 입력
   설명 : 인접한 발열사 사이 간격을 "외곽 사이 거리" 기준으로 입력한다.
   입력 : 간격 값(mm)
   출력 : 경로 생성에 사용할 간격
   비고 : -

FR-1.5  삽입 깊이 입력
   설명 : 발열사의 삽입 깊이를 입력한다.
   입력 : 깊이 값(mm)
   출력 : 경로 생성에 사용할 깊이
   비고 : -


■ ② 발열사 경로 자동 생성

FR-2.1  평판 경로 생성
   설명 : 선택한 평판 면 위에 지정한 간격으로 발열사 경로를 자동 생성한다.
   입력 : 적용면, 간격, 삽입 깊이
   출력 : 평판 위 발열사 경로
   비고 : -

FR-2.2  곡면 경로 생성
   설명 : 선택한 곡면 면 위에 지정한 간격으로 경로를 생성한다. 
   입력 : 적용면, 간격, 삽입 깊이
   출력 : 곡면 위 발열사 경로
   비고 : 곡률이 큰 곡면의 정밀 배치는 PHASE 2에서 구현 (PHASE 1 에서는 근사치로 구현)

FR-2.3  간격·삽입 깊이 유지
   설명 : 생성된 경로는 지정한 간격(외곽 사이 거리)과 삽입 깊이를
          유지한다.
   입력 : -
   출력 : 간격·깊이가 반영된 경로
   비고 : -

FR-2.4  경계·구멍 고려
   설명 : 면의 외곽경계를 고려하여 배치한다. 
   입력 : 면 경계
   출력 : 경계가 반영된 경로
   비고 : 구멍을 우회하는 자동 배치는 PHASE 2에서 구현

FR-2.5  배치 영역 지정
   설명 : 면 전체가 아닌 일부 영역에만 배치할 경우, 사용자가 배치영역을 지정한다.
   입력 : 사용자가 지정한 영역
   출력 : 지정 영역에 생성된 경로
   비고 : 배치 영역 지정 방식은 협의필요 (2)


■ ③ 전기적 조건 검토 및 회로 구성

FR-3.1  경로 길이 계산
   설명 : 생성된 발열사 경로의 전체 길이를 계산한다.
   입력 : 생성된 경로
   출력 : 총 길이
   비고 : -

FR-3.2  저항·전류·전력 계산
   설명 : 길이와 재원으로 저항·전류·전력을 계산하고, 허용 전류·전력 범위와 비교하여 판정한다.
   입력 : 경로 길이, 전기 조건
   출력 : 회로별 저항·전류·전력, 허용 범위 판정 결과
   비고 : 계산식은 발주처 제공 자료 기준

FR-3.3  적용 가능 영역 산출
   설명 : 전원 한도 내에서 발열사를 적용할 수 있는 영역을 산출하여 표시한다.
   입력 : 전원 조건, 경로
   출력 : 적용 가능 영역
   비고 : 산출 방식에 대한 발주처 협의 필요

FR-3.4  회로 분할
   설명 : 필요한 경우 여러 발열 구역으로 나누어 회로를 구성한다. 연결부 위치는 사용자가 직접 지정한다.
   입력 : 사용자가 지정한 연결부, 경로
   출력 : 분할된 회로 구성
   비고 : 연결부 자동 최소화는 PHASE 2


■ ④ 결과 확인 및 저장

FR-4.1  3D 표시
   설명 : 3D 모델 위에 발열사 경로와 적용 영역을 표시한다.
   입력 : 생성된 경로, 적용 영역
   출력 : 화면 표시
   비고 : -

FR-4.2  전기 사양표 출력
   설명 : 회로별 발열사 길이·저항·전류·전력 사양표를 출력한다.
   입력 : 회로 구성, 계산 결과
   출력 : 전기 사양표
   비고 : 출력 형식은 협의 (3)

FR-4.3  결과 저장
   설명 : 생성된 경로를 3D(STEP/STP) 및 2D(DXF) 파일로 저장한다.
   입력 : 경로, 설정값
   출력 : 3D 파일(STEP/STP), 2D 파일(DXF)
   비고 : -


3. 협의 필요 사항
----------------------------------------------------------------
아래 3가지 사항에 대해 결정이 필요합니다.
결정 전에는 일반적인 방식으로 진행하고, 결정되면 반영합니다.

(1) 적용면(발열면) 선택 방법
   - 하나의 발열면이 3D 모델에서는 여러 개의 작은 면으로 나뉘어 있는
     경우가 있으므로, 발열면을 지정하는 방법을 정해 주세요.
   - 예시
       · 여러 면을 클릭하여 선택
       · 범위를 드래그 하여 해당 범위 내의 모든 면들을 선택

(2) 발열사 배치 영역 지정 방법
   - 면 전체가 아니라 일부 영역에만 배치할 때, 영역을 지정하는 방법을
     정해 주세요.
   - 예시
       · 면의 경계를 기준으로 자동 지정
       · 3D 모델의 평면에서 직접 그리기

(3) 전기 사양표 출력 형식
   - 회로별 발열사 길이·저항·전류·전력을 어떤 형식으로 출력할지
     정해 주세요.
   - 예시
       · 2D 도면 안에 표로 삽입
       · 별도 파일(Excel·CSV)로 저장
   - 사내에서 사용하는 표 양식이 있으면 공유 부탁들비니다.


4. 제공 요청 자료
----------------------------------------------------------------
   - 발열사 재원 : 직경, 단위 길이당 저항, 사용 전압, 허용 전류·전력, 기준 발열량
   - 전기 계산식 : 길이·저항·전류·전력 계산식과 허용 판정 기준
   - 몰드 추가 샘플 파일
   - 전기 사양표 양식 (있을 경우)
   - 회로 구성 관련 규칙
   - 사내 도면 표준 (레이어·치수 등, 있을 경우)
   - 배치 제외 영역 관련 규칙

5. 최종 납품 결과물
----------------------------------------------------------------
   - 프로그램 실행 파일 및 설치 파일
   - 수정 가능한 소스코드
   - 사용자 매뉴얼
