발열몰드 자동설계 프로그램 - PHASE 1 기능 구현 명세서
================================================================

문서 버전 : v0.1 (2026-10-14)
문서 성격 : PHASE 1 납품 범위 및 동작 정의.
            미확정 협의 항목은 "결정안(옵션+권고+기본값)"으로 포함하여 착수 전 협의에서 확정한다.

----------------------------------------------------------------
1. 범위 및 전제
----------------------------------------------------------------
- 별도 실행 프로그램 
- Windows 데스크탑 전용, 기본 WPF UI
- 입력 : STEP/STP 모델 ->  출력 : STEP/STP (경로 3D) + DXF (2D 도면)
- 발주처 요청 기능 전체를 최소형태로 구현.
- 2D 도면은 투영도면 기준.
- 인도 조건 : 수정 가능한 소스코드 + 사용자 매뉴얼, 개발 완료 후 전량 인도
- 열해석 제외. 전기 재원·계산식은 발주처 제공 기준이며 정합성에 대한 책임은 지지 않습니다.


----------------------------------------------------------------
2. 기능 명세
----------------------------------------------------------------

[2.1] ① 형상·설계조건 입력
- STEP/STP 로드
- 적용면 선택
    협의 필요사항 : '3. 협의 항목 결정안의 PHASE 1-1 확인'
- 전기 파라미터 입력
    발열사 직경·단위 길이당 저항·입력 전압(또는 최대 허용 전압)·허용 전류·
    허용 전력·기준 발열량 - 입력 UI 및 템플릿 사용
- 간격·삽입 깊이
    발열사 간격은 외곽 사이 거리 기준으로 입력
    삽입 깊이는 수치 및 시각화 처리

[2.2] ② 발열사 경로 자동 생성
- 평판 경로
- 곡면 경로
    PHASE 1 근사 : UV 스케일 보정 + Seam 처리(완만 곡면 대상)
    원통면 UV 비등방 문제 실측 확인 완료(판정보고서 E5)
- 경계·구멍 고려
    외곽 마진 + 홀 자동 제외. 홀 구간 분절 허용(홀 자동 회피는 PHASE 2)
- 배치 영역 지정
    [협의 PHASE 1-2] 스케치 방식 - 3.2 결정안, 확정 대기

[2.3] ③ 전기적 검토·회로 구성
- 길이·저항·전류·전력 계산
    옴의 법칙 기반 표준 계산(발주처 제공 산식 우선)
- 전원 한도 내 적용 가능 영역 산출
    한도 대비 판정·표시
- 회로 분할
    사용자가 연결부 위치를 직접 선택하는 방식(자동 최소화 아님 - 제안서 기재 방식)

[2.4] ④ 결과 확인·저장
- 3D 표시
    경로·적용 영역 오버레이 - MVP 이관
- 사양표 출력
    [협의 PHASE 1-3] 출력 형식 - 3.3 결정안, 확정 대기
- 저장
    DXF(투영 도면) + STEP(3D 경로) + 프로젝트(JSON)


----------------------------------------------------------------
3. 협의 항목 결정안 (착수 전 협의 확정 대상)
----------------------------------------------------------------

[3.1] PHASE 1-1 적용면 선택 방식 - "하나로 보이는 면 ≠ 하나의 B-rep 면"
- 문제
    시각적으로 한 면이어도 3D 모델 내부에서는 다수 면으로 분할되어 있음
    (샘플 모델 : 전체 664면·평면 317면). 단일 면 선택만으로는 적용면 지정 불가.
- 옵션 / 판단
    A. 다중 선택 누적(CTRL/드래그) + 면 목록 관리
       -> 권고(기본). MVP 면 콤보 확장으로 비용 낮음
    B. 동일 평면(co-planar) 인접 면 자동 병합
       -> 포함 권장. 분할 평면 문제 실효 해소
    C. 접선 연속 곡면 자동 전파
       -> PHASE 2 (판정 규칙 협의 필요)
- 발주처 확정 요청
    병합 기준(B 허용 여부) / 면 목록 UI(명칭·색상 구분) /
    "적용면 그룹" 저장 개념 필요 여부
- 확정 전 기본값 : A + B(동일 평면)

[3.2] PHASE 1-2 발열사 배치 영역 스케치 방식
- 문제
    적용면 전체가 아닌 일부 영역에 배치할 때의 영역 지정 방식
    (제안서 기재 : "그리기 도구로 배치영역 직접 스케치")
- 옵션 / 판단
    A. 면 경계 기준 자동 영역(외곽 오프셋 + 홀 제외)
       -> 기본 제공(스케치 불요 케이스)
    B. 3D 면 위 직접 스케치(사각형/다각형/자유곡선 -> 닫힌 영역)
       -> 권고. 평면 면 한정 PHASE 1, 곡면 위 스케치는 PHASE 2
    C. 2D 투영 스케치 -> 역투영
       -> 대안(평면 한정)
- 발주처 확정 요청
    그리기 도구 종류 / 영역 경계-발열사 최소 이격(안전거리) /
    영역 수정(편집·이동·삭제) UX
- 확정 전 기본값 : A + B(평면 한정)

[3.3] PHASE 1-3 전기 사양표 출력 형식
- 문제
    "회로별 발열사 길이 및 전기적 사양표"의 출력처·형식
- 옵션 / 판단
    A. DXF 도면 내 표 엔티티(회로별 : 길이·저항·전류·전력)
       -> 권고
    B. 별도 문서 동시 출력(CSV/Excel/HTML)
       -> A와 병행 권장
    C. 화면 표 전용
       -> 보조
- 발주처 확정 요청
    표 항목·단위·자릿수 / 도면 내 위치·글꼴·선 스타일 /
    사내 표준 양식 존재 여부(있으면 견본 수령)
- 확정 전 기본값 : A + B


----------------------------------------------------------------
4. 검수 기준 (PHASE 1 납품 판정)
----------------------------------------------------------------
샘플 몰드 기준 시나리오 :
1. STEP 로드 -> 적용면(다중) 선택 -> 전기 파라미터 입력
2. 경로 생성(간격·외곽 사이 거리) -> 3D 표시
3. 전기 계산·회로 분할(사용자 연결부 지정) -> 사양표 출력
4. DXF + STEP 저장 -> AutoCAD에서 열람·확인

- 품질 전제 : 평면 = 정밀 등간격 / 곡면 = 근사 등간격(완만 곡면)


----------------------------------------------------------------
5. 착수 전 수령 자료 (필수 - 미수령 시 착수 불가·공수 변동)
----------------------------------------------------------------
A1. 발열사 재원
    직경·단위 길이당 저항(Ω/m)·사용 전압(입력/최대 허용)·
    허용 전류·허용 전력·기준 발열량
A2. 전기 계산식
    길이->저항->전류->전력 산식, 허용 판정 기준식
    (부재 시 표준 물리식으로 가정 진행)
A3. 삽입 깊이 정의 및 적용 방식 (홈 모델링 여부) - 공수 변동 최대 항목
A4. 발열사 간격 기준 확인
    외곽 사이 거리 / 중심 간 거리 여부 + 실무 간격 값·범위
A5. 대상 몰드 샘플 STEP 파일 (실 제품 1종 이상)
    - 면 분할 실태·곡면 비중 확인용
A6. 적용면 지정 예시 : 배치 대상 면을 이미지 또는 면 번호로 표시 - [PHASE 1-1 확정 자료]
A7. 배치 영역 예시 : 실제 배치 영역 형태(전체/부분) 이미지 - [PHASE 1-2 확정 자료]
A8. 사양표 표준 양식 (사내 양식 존재 시 견본) - [PHASE 1-3 확정 자료]
A9. 회로 구성 실무 규칙
    단자 위치 관례·발열사 최대 연속 길이·직/병렬 관례


----------------------------------------------------------------
6. 개발 중 수령 자료 (착수 후 2주 내)
----------------------------------------------------------------
B1. MVP 샘플 DXF에 대한 AutoCAD 검수 의견 (현재 대기 중)
B2. 도면 표준 : 레이어·치수·글꼴 규약 (사내 표준 존재 시)
B3. 제외영역 규칙 : 배치 불가 영역 관례·영역 경계 안전거리
B4. 사용 3D CAD 프로그램 및 3D 저장 형식 요구(STEP 외 여부)
