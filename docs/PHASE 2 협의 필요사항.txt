발열몰드 자동설계 프로그램 - PHASE 2 협의 필요사항
================================================================

문서 버전 : v0.2 (2026-10-14)
문서 성격 : PHASE 2 범위·공수 확정 전 발주처 확인 사항
            (발주처 제출용으로 PHASE 1 명세서와 함께 송부 가능)


----------------------------------------------------------------
1. 2D 도면 표현 형태 (기준 재확인)
----------------------------------------------------------------
- PHASE 1·견적 기준 = 투영도면임을 명시적으로 재확인한다.
  - 현재 견적 범위의 2D 도면은 3D 모델의 투영(정면/평면/측면 등) 결과이다.
  - 투영도면의 표현 규약(뷰 구성·레이어·치수·사양표 포함)은
    PHASE 1 협의 항목으로 진행한다.
- 투영도면으로는 제작용 전개도를 대체할 수 없다.
  -> 2장 전개도 협의로 분리한다.


----------------------------------------------------------------
2. 전개도 (핵심 협의)
----------------------------------------------------------------

[2.1] 배경·판단
- 발열사 실제 제작·시트 재단에는 2D 전개도가 필요할 수 있음
  (제출 제안서 "구현 리스크" 항목으로 고지된 사항).
- 투영 도면으로 전개도 구현은 곤란
  - 곡률이 큰 면은 투영 시 길이·각도 왜곡이 커 오차가 크다.
- 완전한 전개도 자동 생성은 불가
  - 전개 가능 면(원통·원뿔 등)은 정밀 전개 가능하나,
    이중곡률 면은 완전 전개 자체가 수학적으로 불가 -> 근사 전개 전제.
- 규칙 기반 일괄 자동 생성 불가
  - 형상마다 근사 방식·수동 보정이 필요하다.

[2.2] 발주처 확인 요청
1) 전개도 필요 여부 (불필요 / 특정 곡면만 / 전체)
2) 전개 대상 : 발열사 경로선만? / 적용면 전체(시트 재단용)?
3) 허용 오차·정밀도 기준 (제작 공차)
4) 전개 불가능면(이중곡률) 처리 : 근사 수용 여부·수동 보정 병행 가능 여부
5) 산출 형식 : DXF 전개도면 / 별도 문서

[2.3] 조건 고지
- 전개도는 PHASE 1 견적 범위 외이며, 별도 공수로 PHASE 2에서 산정한다.
- 공수 확정 절차 제안 :
  대상 곡면 샘플 수령 -> 1개 면 파일럿 전개 검증
  -> 오차·정밀도 합의 -> 확정 견적.


----------------------------------------------------------------
3. PHASE 2 고도화 후보 (PHASE 1 완료 시점에 우선순위·공수 재확정)
----------------------------------------------------------------
H1. 전개도
    전개 가능면 정밀·이중곡률 근사 전개 (2장 협의)
    - 협의 결과에 따라 최우선
H2. 곡면 경로 정밀화
    측지(geodesic) 기반 실길이 등간격 + Seam 정밀 처리
    (PHASE 1은 UV 스케일 보정 근사 - 원통면 비등방 실측 확인 완료)
    - 우선순위 : 높음
H3. 홀·장애물 자동 회피
    홀·보스·기둥 우회, 끊김 없는 연속 발열사 라우팅
    (PHASE 1은 홀 구간 분절 허용)
    - 우선순위 : 높음
H4. 인접면 연속 배치
    면 경계를 넘어 이웃 면으로 이어지는 연속 배치(모서리 월담 라우팅)
    (PHASE 1은 면 단위 독립 배치 - 다중 면 적용면에서 면 간 연결 필요 시 대응 불가)
    - 우선순위 : 높음
H5. 적용면 자동 병합 확장
    접선 연속 곡면 자동 전파·원클릭 영역 선택
    (PHASE 1은 동일 평면 병합까지만 - 곡면 다수 분할 시 수동 다중 선택 필요)
    - 우선순위 : 중간
H6. 곡면 위 배치 영역 스케치
    3D 곡면 위 직접 영역 그리기(UV 도메인 스케치 + 3D 실시간 피드백)
    (PHASE 1 스케치는 평면 면 한정)
    - 우선순위 : 중간
H7. 회로 분할 자동화
    연결부 위치 자동 제안·연결부 수 최소화(실무 규칙 반영)
    (PHASE 1은 사용자 직접 지정 방식 - 자동화는 편의 개선)
    - 우선순위 : 중간
H8. 패턴 라이브러리
    나선·동심·방향 지정 등 패턴 종류 추가 + 구조화
    (PHASE 1은 사행 serpentine 1종)
    - 우선순위 : 중간
H9. DWG 직접 출력
    DWG 저장(ACadSharp 채택 시)
    (PHASE 1은 DXF - 발주처 CAD 환경에 따라 필요)
    - 우선순위 : 중간 (사용 CAD 확정 후)
H10. 일괄 처리
    다수 면·다수 몰드에 동일 조건 일괄 적용·일괄 출력
    (PHASE 1은 면 단위 반복 작업)
    - 우선순위 : 낮음

- 제외·보류 :
  * 간격 자동 산정(열량↔간격 변환) - 협의 결과 범위에서 제외
  * 발열 밀도 시각화 - 열해석 범위 제외와 혼동 우려, 요구 확인 후 재검토
  * 배치 시나리오 A/B 비교 - 요구 존재 확인 전 우선순위 낮음
  * IGES 등 입력 포맷 확장 - 발주처 사용 CAD 미확정, 요구 확인 후
  * 실시간 성능 고도화 - 성능 요구사항 미확정(현 실측 : 로드 0.8초·
    HLR 2초·사행 84ms), 요구 확정 후 판단

- 우선순위 기준 :
  ① 제작 실무 직결성(H1~H4)
  ② PHASE 1 협의에서 미룬 항목(H5·H6)
  ③ 편의 개선(H7~H10)
  최종 우선순위는 PHASE 1 진행 중 발주처 실사용 피드백으로 재조정한다.


----------------------------------------------------------------
4. PHASE 2 수령 자료 (PHASE 1 완료 전 수령 시 PHASE 2 공수 확정 가능)
----------------------------------------------------------------
C1. 전개도 대상 곡면 샘플 STEP (전개 필요 면 1개 이상)
    - 파일럿 전개 검증용
C2. 전개도 필요 여부·대상 범위 (경로선만/면 전체)
C3. 전개도 허용 오차·정밀도 기준 (제작 공차)
C4. 곡면 정밀화 대상 범위 : 어느 곡면까지 정밀 등간격이 필요한지
