발열몰드 자동설계 프로그램
PHASE 2 협의 필요사항
================================================================

문서 버전 : v1.0 (2026-10-14)


1. 2D 도면 안내
----------------------------------------------------------------
- PHASE 1의 2D 도면은 3D 모델을 투영한 도면입니다. (정면·평면·측면 등)
- 투영 도면은 발열사를 실제로 재단·제작하는 전개도와는 다릅니다.
  곡률이 큰 면은 투영할 때 길이·각도가 왜곡되어 오차가 커집니다.
- 전개도가 필요하신지, 필요하다면 어떤 형식인지 알려 주세요.


2. 전개도 (별도 협의)
----------------------------------------------------------------
- 전개도는 PHASE 1 범위에 포함되지 않으며, 별도 개발로 진행합니다.
- 원통·원뿔처럼 펼칠 수 있는 면은 정밀하게 펼칠 수 있습니다.
- 이중 곡률 면은 완전히 펼치는 것이 수학적으로 불가능하여 근사로
  제공하며, 형상에 따라 사람이 일부 보정해야 합니다. 모든 형상을
  자동으로 처리하는 것은 어렵습니다.
- 진행 방법
    전개도가 필요한 곡면 샘플을 받아 1개 면을 시험 제작하고,
    오차 수준을 합의한 뒤 개발 범위와 일정을 확정합니다.

확인 부탁드립니다.
    1) 전개도 필요 여부 (불필요 / 일부 곡면만 / 전체)
    2) 전개 대상 (발열사 선만 / 면 전체)
    3) 허용 가능한 오차
    4) 펼칠 수 없는 면의 처리 방법 (근사 허용 여부)
    5) 전개도 저장 형식 (DXF 등)


3. PHASE 2에서 추가 개발이 가능한 기능
----------------------------------------------------------------
PHASE 1 납품 후 아래 기능을 추가로 개발할 수 있습니다.
필요 여부와 우선순위를 알려 주시면 범위와 일정을 산정합니다.

    - 곡면 정밀 배치 : 곡률이 큰 곡면도 정밀한 등간격으로 배치
    - 홀·장애물 자동 회피 : 구멍과 장애물을 피해 발열사를 끊김 없이 배치
    - 이웃 면 연결 배치 : 면 경계를 넘어 여러 면에 연속으로 배치
    - 적용면 자동 묶음 : 이웃한 곡면까지 자동으로 선택
    - 곡면 위 영역 그리기 : 곡면 위에서 배치 영역을 직접 지정
    - 회로 자동 분할 : 연결부 위치를 자동으로 제안
    - 배치 패턴 추가 : 나선·동심 등 다양한 배치 패턴
    - DWG 출력 : 도면을 DWG 형식으로 저장
    - 일괄 처리 : 여러 면·여러 몰드에 같은 조건을 한 번에 적용


4. PHASE 2를 위해 필요한 자료
----------------------------------------------------------------
    - 전개도용 곡면 샘플 모델 (전개가 필요한 면 1개 이상)
    - 전개도 필요 여부와 대상 범위
    - 전개도 허용 오차 기준
    - 정밀 배치가 필요한 곡면 범위
